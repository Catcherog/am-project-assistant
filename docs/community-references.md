# Community project references

These projects inform the presentation and contribution workflow of this repository. No affiliation or endorsement is implied, and no source code was copied from them into this preview.

| Reference | Practice worth studying | Application here |
| --- | --- | --- |
| [LangBot](https://github.com/langbot-app/LangBot) and its [contribution guide](https://github.com/langbot-app/LangBot/blob/master/CONTRIBUTING.md) | Clear entry points for users, plugins, documentation, and contributors | Separate audience paths and small, scoped contributions |
| [LangGraph](https://github.com/langchain-ai/langgraph) | Explain the purpose of infrastructure and link capabilities to documentation | Describe evidence and workflow responsibilities without overstating product maturity |
| [Sierra's current tau-bench repository](https://github.com/sierra-research/tau2-bench) | Pin evaluation tasks and explain when versions are not comparable | Freeze future datasets and report version, split, and evaluation boundaries |
| [Feishu/Lark OpenAPI MCP](https://github.com/larksuite/lark-openapi-mcp) | A platform-specific tool integration with an existing issue and PR workflow | Submit independently reproducible upstream fixes through a fork |

References were checked on 2026-11-11. Their features, contribution policies, and evaluation versions may evolve. In particular, the older [tau-bench repository](https://github.com/sierra-research/tau-bench) directs users to the maintained repository; reproductions must record an exact revision rather than rely on a mutable default branch.
