# Security and sensitive information

This repository contains an R8 source preview, documentation and synthetic examples. It is not a production deployment package with a support or response-time guarantee.

Please report suspected credentials, personal information, confidential business material, or exploitable publication tooling through [GitHub private vulnerability reporting](https://github.com/Catcherog/am-project-assistant/security/advisories/new). Avoid public issues and PR attachments containing the suspected material.

Describe the affected path or commit, the type of issue, and a minimal sanitized reproduction. Do not send real access tokens, database exports, customer files, or production chat logs. A maintainer may request a safer reproduction if needed.

If private reporting is unavailable, open an issue that says only that a private reporting channel is needed; do not publish the sensitive details. No response-time guarantee is currently offered.

Deletion from the current branch does not erase Git history. A confirmed exposure may require credential rotation, history remediation, and coordination with affected owners. The publication maintainer will record the scope and route operational remediation to the relevant owner.
