# AM 项目助理

[English](README.md) · [项目说明](docs/overview.md) · [当前状态](docs/status.md) · [参与贡献](CONTRIBUTING.md)

AM 是持续迭代中的飞书项目管理助理，关注项目问答和执行建议是否有充分依据：计划日期、预计进度、实际完成、验收和批准分别记录；资料、对象或授权发生变化时，重新核对相关结果。

**当前仓库已加入 R8 源码预览版。** [runtime](runtime/) 收录脱敏后的网关、第一方配套模块、测试和合成配置示例，共 464 份文件，其中 449 份为 Python 源文件。原开发历史、本机启动适配、CLI 登录状态、真实配置、key、token、业务记录和模型权重没有上传。可先按[离线快速开始](docs/quickstart.md)运行；真实飞书部署仍需单独配置和验证。

## 从哪里开始

- 想了解用途：阅读[流程与术语](docs/overview.md)。
- 想参与讨论：查看[十二个合成案例](examples/README.md)，指出预期答案的遗漏或歧义。
- 想参与开源：阅读[贡献说明](CONTRIBUTING.md)和[公开资料要求](docs/publishing.md)。
- 想了解论文：查看[研究方案](research/protocol.md)、[相关工作](research/related-work.md)和[论文正文起稿](research/manuscript-draft.md)。
- 想阅读或验证源码：查看[离线快速开始](docs/quickstart.md)和[源码版本说明](docs/source-release.md)。
- 想接入真实飞书：先核对[部署与发布清单](docs/release-checklist.md)，不要把合成示例当成实际配置。

## 现阶段可以贡献什么

欢迎改进文档、翻译、案例及评测方法。案例必须保留来源、时间、条件和允许行为之间的关系，并清楚区分合成材料与真实研究数据。运行代码和功能迭代由 AM 开发项目负责，社区整理不会直接改变运行环境。

使用 Python 3.9 及以上版本检查本仓库文档和案例结构：

```bash
python3 tools/check_publication.py
```

这个命令不运行 AM、不调用模型、不连接飞书，也不构成业务验收。

## 公开范围

当前材料经过面向公开发布的检查；案例为重新编写的虚构内容，没有搬运真实聊天、业务台账、内部身份或配置。扫描只能发现部分模式，提交者仍需检查上下文是否可能识别真实人员或项目。
